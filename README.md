## 🚀 Featured Projects

### 🔬 `pos-laundary-tests` — iMetanic POS Automation Suite
> **Robot Framework · SeleniumLibrary · GitHub Actions · Python**

Enterprise-grade UI automation suite for a multi-vertical POS system covering Laundry, Grocery, Restaurant, Salon, and Carwash modules.

- ✅ **Architecture:** Page Object Model with centralized YAML/JSON config
- ✅ **Coverage:** Login, Signup, Order, Cancel, Return, Refund, E2E flows (186+ tests)
- ✅ **CI/CD:** Full GitHub Actions pipeline with email reporting via SMTP/OAuth2
- ✅ **Debugging:** Resolved STARTTLS conflicts, tag filter bugs, XML parser silent failures, Linux path issues
- ✅ **Data Layer:** YAML locator resolution, dynamic config_parser, JSON test data

```
pos-laundary-tests/
├── resources/
│   ├── pages/         ← POM keyword files per module
│   ├── locators/      ← YAML locator configs
│   └── data/          ← JSON test data
├── tests/             ← Test suites by business type
├── config/            ← Environment configs
└── .github/workflows/ ← CI/CD pipelines
```

I have created and managed **100+ Jira bugs and tasks** across QA, INT, and PROD environments. Defect categories I regularly identify:

```
Framework Design Principles
─────────────────────────────────────────────────────────────────
```
